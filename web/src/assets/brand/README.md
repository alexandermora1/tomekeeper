# Brand files

`google-g.png` (or `google-g.svg`): Google's "G" logo for the "Sign in with Google" button. Google's branding
rules say it must be their own file, unchanged, so it isn't in the repository by default. Download it from
Google's branding guidelines (https://developers.google.com/identity/branding-guidelines) and save it here.
The button picks it up by itself.
